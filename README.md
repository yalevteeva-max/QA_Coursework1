# Курсовой проект по профессии "Инженер по тестированию"

Автоматизация тестирования комплексного сервиса, взаимодействующего с СУБД и API платежной системы.

## Предварительные требования

Перед запуском тестов убедитесь, что на вашем компьютере установлены Java 17 или выше, Docker Desktop, Python 3.10+ и Allure Commandline (для генерации отчетов).

## Инструкция по запуску

### Шаг 1. Запуск тестируемого приложения (Docker)

Откройте терминал в корне проекта (там, где лежит файл docker-compose.yml) и выполните команду - docker compose up -d. Дождитесь, пока все три контейнера mysql, gate-simulator, aqa-shop запустятся. Проверить статус можно командой docker ps.

### Шаг 2. Подготовка Python-окружения

Создайте и активируйте виртуальное окружение. Для Windows : python -m venv venv, затем .\venv\Scripts\activate. Для macOS / Linux- python3 -m venv venv, затем source venv/bin/activate. Установите зависимости командой -  pip install -r requirements.txt.

### Шаг 3. Запуск автотестов

Для запуска всех тестов и генерации файлов для отчета Allure выполните: pytest tests/ --alluredir=allure-results.

### Шаг 4. Просмотр отчета Allure

Чтобы открыть HTML-отчет в браузере, выполните - allure serve allure-results.

## Результаты тестирования

На данный момент автоматизированы следующие проверки:
- Успешная покупка тура по карте (APPROVED).
- Успешная выдача кредита по карте (APPROVED).
- Проверка записи в СУБД после успешной оплаты (SQL-запрос).
- Негативный сценарий (DECLINED), который падает из-за найденных багов в приложении.

Все найденные дефекты описаны в разделе **Issues** данного репозитория.
